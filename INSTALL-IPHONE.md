# Установка 11/35 на iPhone

Для установки на личный iPhone без платной подписки используется Personal Team в Xcode. На iPhone данные хранятся локально; автоматическая синхронизация через iCloud для этой сборки отключена. Для переноса данных между Mac и iPhone используйте раздел «Перенос данных» в приложении.

## Подготовка

1. На Mac установите Xcode из App Store и один раз запустите его.
2. Скачайте ZIP-архив проекта с GitHub: <https://github.com/mpg2gvbcdt-glitch/euro-auto-macos-ios/archive/refs/heads/main.zip>.
3. Распакуйте архив и откройте файл `EuroAuto.xcodeproj`.

## Запуск на телефоне

1. В Xcode откройте настройки проекта **EuroAuto** и выберите target **EuroAuto**.
2. На вкладке **Signing & Capabilities** включите **Automatically manage signing** и в поле **Team** выберите ваш Apple ID с пометкой **Personal Team**. При первом запуске Xcode может попросить войти в Apple Account.
3. Подключите iPhone к Mac кабелем, разблокируйте его и подтвердите **Доверять этому компьютеру**.
4. В верхней панели Xcode выберите подключённый iPhone как устройство запуска и нажмите ▶.
5. Если iPhone попросит включить режим разработчика, откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включите его и перезапустите iPhone.

Бесплатная Personal Team подходит для тестирования на собственном устройстве. Подписанный профиль действует 7 дней, после чего приложение нужно снова запустить на iPhone из Xcode с подключённого Mac.
